Cache Configuration

Cache limits are set via environment variables and require a container restart.

VariableCurrentDescription
CACHE_MAX_BYTES {{ max_bytes | human_bytes }} Hard limit for total cache size (default: 16G). Suffixes: K, M, G, T.
CACHE_EVICTION_THRESHOLD 0.9 Fraction of max at which proactive eviction starts.
CACHE_EVICTION_TARGET 2G How many bytes to free when eviction runs.
CACHE_MIN_FREE 512M Minimum free disk space to keep for OS.
