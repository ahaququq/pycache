Usage

Configure your build tool to use this cache as a proxy.

Gradle

gradle.user.home=/path/to/this/cache/gradle

Or set GRADLE_USER_HOME environment variable.

Generic HTTP

GET http://cache-host/cache/gradle/8.5/gradle-8.5-bin.zip

If the file is cached, it's served instantly. If not, it's fetched from upstream, cached, then served.
